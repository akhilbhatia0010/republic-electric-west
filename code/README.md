# StaffWare 2.0 – static demo
Open `index.html` directly, or run `python3 -m http.server` in this folder and visit http://localhost:8000.
- `js/data.js` – every module, filter, button and required-filter letter transcribed from `existing-ui/`
- `js/app.js` – routing, filters, report/form/dialog behaviour
- `css/styles.css` – theme (Republic blue #2b73b8, cream, Roboto), light/dark

## Demo status
This preview is **not connected** to StaffwareSQL. All figures are sample data (screens captured 10/27/2026), and actions, forms and saves are no-ops. Dates such as "payroll pending since 10/28/2026" are fixed sample values compared against today's date.
